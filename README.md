## The joke

> Our office printer never jams on a casual printout — it saves it for the day the deadline is today and the boss is standing right behind you.

## How it works

`main.py` (Python standard library only, fully deterministic) writes the joke to `/output/entry.txt` — a single line, 141 characters, well inside the 1–199 character gate.

```sh
python3 main.py
cat /output/entry.txt
```
